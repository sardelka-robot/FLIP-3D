# FLIP 3D Engine 🚀

**FLIP 3D** — это легкий, автономный и высокопроизводительный 3D WebGL-движок от первого лица, написанный на чистом JavaScript с использованием библиотеки Three.js. Движок полностью оптимизирован под мобильные устройства и спроектирован для последующей упаковки в независимые Android `.apk` приложения.

---

## 🌟 Особенности / Features

- **Native Android Viewport Rendering:** Рендеринг в родном Full HD (FHD) разрешении экрана смартфона с умным ограничением Device Pixel Ratio для стабильной производительности без перегрева.
- **Стабильные 60+ FPS:** Максимальная плавность за счет аппаратного ускорения видеокарты (GPU) телефона.
- **Хоррор-атмосфера:** Встроенный глубокий радиальный WebGL-туман (плавное затухание в кромешную тьму) и точечный динамический фонарик, привязанный к камере игрока.
- **Универсальное API (.init):** Полное отделение системного ядра от контента. Любой 3D-лабиринт строится динамически из обычного двухмерного массива (матрицы MAP).
- **Процедурные текстуры:** Движок работает автономно и не требует внешних тяжелых картинок на старте — все текстуры сетки и панелей генерируются кодом.
- **Мобильное управление:** Встроенный отзывчивый полупрозрачный тач-джойстик слева (движение) и чувствительная тач-зона (трекпад) справа для плавного обзора пальцем.
- **Система коллизий:** Реализована физика столкновений камеры со всеми 3D-кубами стен (игрок плавно скользит вдоль стен).

## 🛠️ Как запустить движок / Quick Start

Движок работает через CDN. Для запуска любой игры достаточно вызвать метод `FLIP3D.init()` внизу скрипта, передав туда карту и настройки окружения:

```javascript
// Пример инициализации карты сторонним разработчиком:
const myMap = [,
 ,
 ,
 ,
 ,
 ,
  [1, 1, 1, 1, 1, 1, 1, 1]
];

FLIP3D.init({
    map: myMap,
    flashlight: true,
    fogDensity: 0.06,
    playerSpeed: 0.04
});
```
